# Project Learning Skill

> 把一个陌生的技术项目（框架 / 协议 / 工具 / 平台），转化成一套体系化的学习文档。

## 这是什么

一份**可直接复制使用的 Agent Skill**，用于指导 AI 完成一次完整的项目学习：

从 **README / 官方文档 / 源码结构 / Release Notes / Issues / 社区讨论** 中采集素材，
经过**定位、核心机制、设计权衡、适用边界、竞品对比**的深度分析，
最终产出**分阶段的 Markdown 学习文档集**——含领域地基、项目概览、架构解析、源码深读、机制专题、动手上手、实战项目与应用延展。

Skill 本体在 [SKILL.md](./SKILL.md)。

## 解决什么问题

学一个开源项目，常见三种失败方式：

| 失败方式 | 表现 | 本 Skill 的对策 |
|----------|------|----------------|
| **碎片化** | 东看一个博客、西看一段源码，说不出整体 | 固定四阶段 → 从领域地基到源码深读，逐层推进 |
| **复述化** | 把 README 换个说法抄一遍，没有分析 | Stage B 强制回答八个问题，必须给出权衡与边界 |
| **幻觉化** | 编造 API、命令、版本号，看起来专业实则有毒 | 强制来源标注 + 不确定就写"待核实" |

## 使用方法

### 方式一：作为 Agent Skill 使用（推荐）

把它放进你所用 Agent 的 skills 目录，或直接把 [SKILL.md](./SKILL.md) 全文贴给 Agent。

### 方式二：手动使用

1. 打开 [SKILL.md](./SKILL.md)，按第 1 节准备输入：

   | 输入 | 必选 | 示例 |
   |------|------|------|
   | 目标项目 | 是 | GitHub 地址 / 本地代码路径 / 官方文档站点 |
   | 学习目的 | 是 | 面试准备 / 技术选型评估 / 上手使用 / 架构借鉴 / 内部培训 / 技术分享 |
   | 目标读者水平 | 否 | 零基础 / 有经验工程师 |
   | 侧重点 | 否 | "只看调度与并发" |

2. 按第 2 节的三个 Stage 依次执行：**信息收集 → 深度分析 → 文档生成**。每个 Stage 结束输出阶段小结并暂停确认。
3. 按第 3 节的模板逐章生成文档，交付前跑第 5 节的自检清单。

## 适用场景

- 系统化学习一个陌生的开源项目，而不是碎片化浏览
- 技术选型前的深度调研（要能说清"它凭什么、代价是什么、什么场景别用"）
- 面试 / 答辩 / 晋升材料准备
- 内部分享、新人培训、团队技术布道

## 不适用场景

- 只需要一句话解释某个 API 或某个报错 → 直接查文档
- 拿不到任何原始资料（无仓库、无文档、无代码）→ 先解决资料获取
- 目标不是"学习材料"而是"要改这个项目" → 那是开发任务，不是学习任务

## 产出物长什么样

Skill 产出的是一套文档集：

```
<项目名>-study/
├── README.md                     # 总入口：项目简介、学习路线图、分阶段目录、未覆盖清单
├── LICENSE
└── docs/
    ├── 01-<领域基础>/README.md      # 领域概念与术语铺垫
    ├── 02-<项目概览>/README.md      # 定位、特性、竞品对比
    ├── 03-<架构解析>/README.md      # 分层图、模块职责、数据流、设计模式
    ├── 04-<源码深读>/README.md      # 逐文件拆解到 文件:行号
    ├── 05-<核心机制专题>/README.md  # 协议 / 机制单点讲透
    ├── 06-<安装与上手>/README.md    # 最短路径跑起来 + 配置逐字段详解
    ├── 07..<N>-<机制实战>/README.md # 逐个机制：为什么需要 → 怎么工作 → 怎么用
    ├── <N>-<安全与部署>/README.md
    ├── <N+1>-<实战项目>/README.md   # 2–3 个难度递进的完整项目
    └── <N+2>-<应用延展>/README.md   # 按学习目的生成（面试题库 / 选型报告 / 培训讲义）
```

每一章都遵循同一骨架：**章目标 → 本篇章节目录 → 编号正文章节 → 面试高频题 / 实战练习 → 本章小结 → 下一章导航**。
